 写文章三步走
第 1 步：创建文章

在 Git Bash 里执行（把日期和标题换成你的）：


bash
cd "/d/Zcode Program(myself)/huaoyan-blog-2026"
hugo new posts/2026/08-04-我的文章/index.md
第 2 步：编辑内容

用 VS Code 打开上面生成的那个 index.md 文件。模板长这样：


markdown
---
title: "我的文章"
date: 2026-08-04
categories: ["日常随想"]     ← 改分类
tags: ["随笔"]               ← 改标签
description: "一句话摘要"     ← 首页显示的简介
draft: true                   ← 改成 draft: false 才会发布
---

这里开始写正文，用 Markdown 语法：

## 二级标题

普通文字...

![图片描述](图片文件名.jpg)

[下载链接](/files/某文件.pdf)

> 引用
常用的 Markdown 符号就这几个：

符号	效果
## 标题	二级标题
**加粗**	加粗
![描述](图片.jpg)	插入图片
[文字](链接)	超链接
> 引用	引用块
第 3 步：发布


bash
cd "/d/Zcode Program(myself)/huaoyan-blog-2026"
git add -A && git commit -m "新文章：我的文章标题" && git push
等 1 分钟，刷新博客就看到了。

标签可以随便改吗

已工作 7 秒
完全可以！标签是自由发挥的，你想写什么都行。比如：

心情类：随笔、碎碎念、日常
读书类：文学、科幻、历史、读书笔记
摄影类：摄影、扫街、风光、手机摄影
每篇文章可以打多个标签，Hugo 会自动按标签把文章归类。标签云页面上哪个标签文章多，字就大——不需要你手动管理。

分类也同理，建议稳定少改（4-5 个就够了），标签随意发挥。

Markdown 中，中文的逗号和句号可以正常用吗

已工作 7 秒
完全可以。中文逗号 ， 句号 。 甚至中文书名号 《》 都能正常用，Markdown 不会把它们当成排版符号。

你正常写中文就行，只有这些 英文符号 在 Markdown 里有特殊含义：

符号	Markdown 含义
#	标题
* **	斜体/加粗
[]()	链接
![]()	图片
>	引用
- * 1.	列表

那么居中等排版格式怎么调整呢

已工作 8 秒
Markdown 本身不支持居中，但你的博客配置里开了 HTML 支持，可以这样写：


markdown
<div align="center">

这句话会居中显示

![](图片.jpg)

*图片说明文字*

</div>
常用的排版写法：

效果	写法
居中文字	<div align="center">内容</div>
居中图片	同上，把图片包进去
分割线	---
换行不空行	行尾加两个空格
缩进引用	> 这段是引用
代码块	``` 包起来
基本上就是：常规排版用 Markdown，特殊对齐用 HTML 标签。不用记，随时问我。
